# 📁 Projects

## 📊 Task 1: Retail Sales Exploratory Data Analysis

This project focuses on performing **Exploratory Data Analysis (EDA)** on a retail sales dataset.

The analysis explores:

- Overall sales performance
- Monthly sales trends
- Quarterly sales trends
- Customer demographics
- Sales by gender
- Sales by age group
- Product category performance
- Correlation analysis

### 🛠️ Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

### 📌 Key Insights

- Total Sales: **908,230**
- Total Transactions: **1,987**
- Best Performing Category: **Electronics**
- Highest Sales Age Group: **46–55**
- Highest Sales Gender: **Female**
- Best Performing Quarter: **Q4 2022**

📂 **Project Folder:** `Task_1_Retail_Sales_EDA`

## 👥 Task 2: Customer Segmentation Analysis

This project uses **RFM Analysis and K-Means Clustering** to segment e-commerce customers based on their purchasing behaviour.

The analysis includes:

- Data cleaning and preprocessing
- Customer purchasing behaviour analysis
- Purchase frequency analysis
- Customer lifetime value analysis
- RFM analysis
- Feature standardization using StandardScaler
- Elbow Method
- K-Means clustering
- Customer segment profiling
- Marketing recommendations

### 🛠️ Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

### 📌 Customer Segments Identified

| Segment | Description |
|---|---|
| 🏆 VIP Customers | Highly valuable customers with high spending and purchase frequency |
| 🤝 Loyal Customers | Frequent customers who generate strong revenue |
| 👥 Regular Customers | The largest customer group with moderate purchasing behaviour |
| ⚠️ At-Risk Customers | Customers who have not purchased recently |

📂 **Project Folder:** `Task_2_Customer_Segmentation`
