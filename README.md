This project focuses on performing **Exploratory Data Analysis (EDA)** on a retail sales dataset to identify meaningful patterns in sales performance, customer demographics, product categories, and seasonal trends.

### 🔍 Analysis Includes

- Overall sales performance
- Monthly sales trends
- Quarterly sales trends
- Customer demographics
- Sales by gender
- Sales by age group
- Product category performance
- Correlation analysis

### 🛠️ Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

### 📌 Key Insights

- 💰 **Total Sales:** 908,230
- 🧾 **Total Transactions:** 1,987
- 🏆 **Best Performing Category:** Electronics
- 👥 **Highest Sales Age Group:** 46–55
- 👩 **Highest Sales Gender:** Female
- 📈 **Best Performing Quarter:** Q4 2022

## 🧹 Task 3: Employee Data Cleaning and Preprocessing

This project focuses on cleaning and preprocessing a messy employee dataset to improve its quality, consistency, and usability for further analysis.

The dataset was examined to identify data quality issues such as missing values, incorrect data types, invalid phone number formatting, duplicate records, and potential outliers.

### 🔍 Data Cleaning Performed

- Initial dataset inspection
- Data quality assessment
- Missing value analysis
- Median imputation for missing values
- Duplicate record checking
- Data type conversion
- Join date formatting
- Phone number cleaning
- Outlier detection using the IQR method
- Final data validation
- Before vs After cleaning comparison
- Exporting the cleaned dataset

### 🛠️ Technologies Used

- Python
- Google Colab
- Pandas
- NumPy

### 📌 Key Results

- 📊 **Original Dataset:** 1,020 records and 12 columns
- ⚠️ **Missing Values Before Cleaning:** 235
- ✅ **Missing Values After Cleaning:** 0
- 📅 **Join_Date:** Converted from `object` to `datetime64[ns]`
- 📞 **Negative Phone Numbers:** Reduced from 1,020 to 0
- 🔁 **Duplicate Rows:** 0
- 📉 **Age Outliers:** 0
- 💰 **Salary Outliers:** 0
- 📁 **Final Dataset:** 1,020 records retained

The final cleaned dataset was exported as:

`Cleaned_Employee_Dataset.csv`

📂 **Project Folder:** `Task3-OIBSIP`
